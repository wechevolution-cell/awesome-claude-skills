# Αρχιτεκτονική · Marketplace κωδικών εξαργύρωσης

Κατάσταση: **Φάση 1 (θεμέλια)**. Το design system είναι κλειδωμένο από το εγκεκριμένο concept **C+**.

## 1. Τι είναι

Web εφαρμογή (PWA) με 4 ρόλους. Το ίδιο backend θα εξυπηρετεί αργότερα τις εφαρμογές iOS / Android μέσω του JSON API.

| Ρόλος | Περιβάλλον | Βασική δουλειά |
|---|---|---|
| Καταναλωτής | Δημόσιο site + `/logariasmos` | Καμπάνια → Κατηγορία → Κατάστημα → Υπηρεσία → Κωδικός |
| Επιχείρηση (ιδιοκτήτης) | `/business` | Προσφορές, καταστήματα, προσωπικό, εξαργυρώσεις, αναφορές |
| Υπάλληλος επιχείρησης | `/business/redeem` | Μόνο εξαργύρωση και ιστορικό |
| Αντιπρόσωπος | `/agent` | Δικές του επιχειρήσεις, σύνδεσμος affiliate, προμήθειες, υπο-αντιπρόσωποι |
| Διαχειριστής | `/admin` | Όλα: εγκρίσεις, περιεχόμενο, χρήστες, ρυθμίσεις, εξαγωγές |

## 2. Design system (κλειδωμένο)

- **Concept:** C+ «bold, οι προσφορές μπροστά, προσιτή πολυτέλεια».
- **Εμφανίσεις:** Νύχτα και Ημέρα. Από προεπιλογή ακολουθεί τη συσκευή. Ο χρήστης αλλάζει με το κουμπί 🌙 και η επιλογή του μένει (localStorage). Ο admin ορίζει την προεπιλογή.
- **Χρώματα (tokens στο `assets/css/app.css`):**
  - Νύχτα: `#140A1E` φόντο, `#22122F` επιφάνειες, `#FFF4E6` κείμενο.
  - Ημέρα: `#FFF4E6` φόντο, `#FFFFFF` επιφάνειες, `#1E0F2A` κείμενο.
  - Σταθερά και στις δύο: χρυσό foil (`#F2C14E`→`#D98E2B`), κοραλί προσφοράς `#FF4F3A`, mint για τα δωρεάν `#2BD4A4`.
- **Γραμματοσειρές (self-hosted, χωρίς Google Fonts, για GDPR και ταχύτητα):**
  - Noto Sans Display 900 condensed: τίτλοι, κεφαλαία.
  - Noto Serif Display Italic: λέξεις-έμφαση με luxury αίσθηση.
  - Noto Sans: κείμενο.
  - JetBrains Mono: κωδικοί.
  - Όλες έχουν ελληνικά.
- **Components:** κουμπιά (coral, gold foil, dark, ghost), κάρτα προσφοράς με αυτοκόλλητο έκπτωσης και μπάρα «απομένουν», chips, ticket κωδικού με QR, drawer καλαθιού, toast, sticky buy bar, κάτω dock (κινητό), cookie bar, panels, πίνακες, φόρμες, badges κατάστασης, breadcrumbs, pager, FAQ accordion.
- **Κίνηση:**
  - Hero: η νυχτερινή πόλη ανάβει μία φορά στο φόρτωμα και ζωγραφίζεται ξανά μόνο όταν κουνάς το slider ή το ποντίκι. Δεν υπάρχει συνεχές animation loop.
  - Μικρές αναπηδήσεις (spring) στα κουμπιά προσθήκης.
  - Όλα σβήνουν με `prefers-reduced-motion`.

## 3. Αρχιτεκτονική κώδικα

- PHP 8.1+ χωρίς framework, Composer, npm ή build. Front controller `index.php` και κανόνες rewrite στο `.htaccess`.
- **Βάση:** MySQL / MariaDB στο live, SQLite για τοπικές δοκιμές. Το ίδιο schema γράφεται για τους δύο drivers (`app/migrations.php`) και δημιουργείται αυτόματα στην πρώτη επίσκεψη.
- **Βασικοί φάκελοι:**
  - `app/`: λογική.
  - `app/controllers/`: χειριστές σελίδων.
  - `app/views/`: πρότυπα.
  - `assets/`: css, js, fonts.
  - `uploads/`: εικόνες, χωρίς εκτέλεση PHP.
  - `data/`: SQLite, logs.
  - Τα `app/` και `data/` απαγορεύονται στο web.
- **Γενική μηχανή διαχείρισης (`app/crud.php`):** κάθε οντότητα ορίζεται μία φορά (πεδία, λίστα, scope). Η ίδια μηχανή εξυπηρετεί admin, επιχείρηση και αντιπρόσωπο. Τα `scope` πεδία επιβάλλονται στην αποθήκευση και φιλτράρουν την ανάγνωση, οπότε μια επιχείρηση δεν μπορεί να δει δεδομένα άλλης.

## 4. Βάση δεδομένων

| Πίνακας | Περιεχόμενο |
|---|---|
| `users` | Όλοι οι χρήστες, με `role`: consumer, merchant, staff, agent, admin |
| `businesses`, `stores`, `business_users` | Επιχειρήσεις, υποκαταστήματα, ποιος χρήστης ανήκει πού (ιδιοκτήτης / υπάλληλος, προαιρετικά συγκεκριμένο κατάστημα) |
| `agents` | Αντιπρόσωπος: περιοχή, γονικός αντιπρόσωπος, % και σταθερή προμήθεια, κωδικός affiliate |
| `categories` | Δέντρο κατηγοριών |
| `campaigns`, `campaign_services` | Καμπάνιες (θεματική / χρονική / περιοχής), ιδιοκτήτης (πλατφόρμα / επιχείρηση / αντιπρόσωπος), έγκριση |
| `services`, `service_variants`, `service_stores` | Προσφορές, παραλλαγές (π.χ. 60′ / 90′), σε ποια καταστήματα εξαργυρώνονται |
| `orders`, `order_items` | Παραγγελίες (δωρεάν ή επί πληρωμή), προμήθεια πλατφόρμας |
| `codes` | Ένας κωδικός ανά μονάδα: κατάσταση, λήξη, ποιος / πού / πότε εξαργύρωσε, ποσό που πληρώθηκε |
| `commissions` | Προμήθεια αντιπροσώπου ανά εξαργύρωση |
| `favorites`, `reviews` | Αγαπημένα. Κριτικές μόνο από εξαργυρωμένο κωδικό (UI στη Φάση 2) |
| `settings`, `audit_log`, `messages`, `login_attempts`, `rate_limits`, `password_resets`, `api_tokens` | Σύστημα |

Τα ποσά αποθηκεύονται σε λεπτά του ευρώ (ακέραιοι). Οι ημερομηνίες γράφονται από την PHP, ώρα Ελλάδας.

## 5. Κωδικός και εξαργύρωση

- **Μορφή:** `PREFIX-XXXX-XXXX`. Τα 8 τυχαία ψηφία βγαίνουν από 31 χαρακτήρες χωρίς αυτούς που μπερδεύονται (όχι 0/O/1/I/L).
- **QR:** περιέχει τη διεύθυνση `/business/redeem?code=…`. Αν τον σαρώσει το κινητό του ταμία, ανοίγει κατευθείαν η εξαργύρωση. Αν τον σαρώσει οποιοσδήποτε άλλος, χρειάζεται σύνδεση επιχείρησης.
- **Ταμείο:**
  - Σάρωση με την κάμερα: BarcodeDetector όπου υπάρχει, αλλιώς jsQR.
  - Εναλλακτικά, πληκτρολόγηση. Δέχεται πεζά, κενά και χωρίς παύλες.
- **Δύο βήματα:** πρώτα «Έλεγχος» (δείχνει υπηρεσία, πελάτη, λήξη), μετά «Επιβεβαίωση».
- **Ατομικότητα:** `UPDATE … WHERE status='active'` μέσα σε transaction. Δύο ταμίες ταυτόχρονα δεν μπορούν να εξαργυρώσουν τον ίδιο κωδικό. Ελέγχεται και ότι ο κωδικός ανήκει στην επιχείρηση.
- Κάθε εξαργύρωση γράφει audit και, αν η επιχείρηση έχει αντιπρόσωπο, προμήθεια.

## 6. Πληρωμές

- Η Φάση 1 έχει **δοκιμαστικό πάροχο**, ώστε όλη η ροή (pending → paid → κωδικοί) να δουλεύει.
- Ο πραγματικός πάροχος με λειτουργία marketplace (π.χ. Viva Wallet Marketplace, Stripe Connect) μπαίνει σε 2 συναρτήσεις στο `app/payments.php`.
- Τα ποσά για αποδόσεις υπάρχουν ήδη: `orders.platform_fee_cents`, `codes.paid_cents`. Υπάρχει και εξαγωγή `payouts.csv` (μικτά / προμήθεια / προς απόδοση ανά επιχείρηση).

## 7. JSON API v1 (για την εφαρμογή κινητού)

| Μέθοδος | Διαδρομή | Auth |
|---|---|---|
| POST | `/api/v1/auth/login` `{email,password,device}` → `{token}` | — |
| POST | `/api/v1/auth/logout` | Bearer |
| GET | `/api/v1/me` | Bearer |
| GET | `/api/v1/categories` · `/api/v1/campaigns` · `/api/v1/offers?k=&t=&perioxi=&q=&page=` · `/api/v1/offers/{slug}` | — |
| GET | `/api/v1/me/codes` | Bearer |
| POST | `/api/v1/business/redeem` `{code, confirm}` | Bearer (επιχείρηση / υπάλληλος) |

Τα tokens αποθηκεύονται μόνο ως hash (SHA-256). Υπάρχει όριο προσπαθειών στη σύνδεση και στην εξαργύρωση.

## 8. Διαδρομή προς τα app stores

1. **Τώρα:** PWA.
   - Εγκαθίσταται από τον browser, με εικονίδιο, manifest και shortcuts.
   - Λειτουργεί offline: ο τελευταίος κωδικός μένει διαθέσιμος για το ταμείο και η οθόνη μένει αναμμένη (wake lock).
2. **Google Play:** η PWA μπαίνει μέσω Trusted Web Activity (TWA) χωρίς νέο κώδικα. Χρειάζεται λογαριασμός Google Play Developer και αρχείο `assetlinks.json`.
3. **iOS App Store:** η Apple συνήθως απορρίπτει εφαρμογές που είναι μόνο ιστότοπος (guideline 4.2).
   - Προτείνεται κέλυφος Capacitor πάνω στο ίδιο API.
   - Με native λειτουργίες: push ειδοποιήσεις λήξης κωδικού, native σαρωτή, Apple Wallet pass για τον κωδικό.
4. Όλα χρησιμοποιούν το ίδιο API v1. Δεν χρειάζεται δεύτερο backend.
