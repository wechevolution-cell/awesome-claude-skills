# ANV Financial Advisors: ιστότοπος (PHP + SQLite)

Πολυσέλιδος ιστότοπος με δικό του admin, για Hostinger Shared Hosting (LiteSpeed/Apache).
Δεν χρειάζεται Composer, npm ή build. Η βάση δημιουργείται μόνη της στην πρώτη επίσκεψη.

- **Design:** Concept C «Ορίζοντας»: τοπίο σε στρώσεις, κάρτες «γυαλιού», χρώματα από το λογότυπο.
- **Σελίδες:** Αρχική, 3 υπηρεσίες (Λογιστικά, Ασφάλειες, Ρεύμα) με 16 υποσελίδες, Η εταιρεία, FAQ, Επικοινωνία (χάρτης + ωράριο, χωρίς φόρμα), Απόρρητο, Cookies, Όροι, 404/410/451/503.
- **Admin `/admin/`:** σελίδες με live SEO/AEO analyzer, εισαγωγή markdown, πολυμέσα, ανακατευθύνσεις, 404 Monitor, ρυθμίσεις (στοιχεία, ωράριο, χάρτης, social, GA4, Search Console), backup.

---

## 1. Απαιτήσεις

| | |
|---|---|
| PHP | **8.1 ή νεότερη** (προτείνεται 8.2/8.3) |
| Επεκτάσεις | `pdo_sqlite`, `mbstring`, `gd` (με WebP), `fileinfo`, `zip`. Προαιρετικά: `intl` |
| Server | Apache ή LiteSpeed με `mod_rewrite` (υπάρχει στο Hostinger) |

Στο Hostinger: **hPanel → Websites → Manage → Advanced → PHP Configuration**. Επιλέξτε PHP 8.2+ και, στην καρτέλα *PHP extensions*, βεβαιωθείτε ότι είναι τσεκαρισμένα τα `pdo_sqlite`, `gd`, `fileinfo`, `zip`, `mbstring` και `intl`.

## 2. Ανέβασμα στο Hostinger

> **Ποτέ upload πάνω σε live site χωρίς backup.** Αν υπάρχει ήδη κάτι στο `public_html`, κατεβάστε το πρώτα (File Manager → επιλογή όλων → Compress → Download).

1. hPanel → **Files → File Manager** → άνοιγμα του `public_html`.
2. **Upload** → `anv-site-php.zip`.
3. Δεξί κλικ στο zip → **Extract** → ως φάκελο προορισμού βάλτε `.` (μέσα στο `public_html`). Τα `index.php`, `.htaccess`, `app/` κ.λπ. πρέπει να βρίσκονται απευθείας στο `public_html`.
4. Διαγράψτε το zip.
5. Δικαιώματα: οι φάκελοι `data/` και `uploads/` πρέπει να είναι εγγράψιμοι (755, που είναι η προεπιλογή του Hostinger).
6. Ανοίξτε το domain. Η βάση (`data/site.sqlite`) δημιουργείται αυτόματα με όλες τις σελίδες.

Τα κρυφά αρχεία (`.htaccess`) δεν φαίνονται πάντα στο File Manager. Ενεργοποιήστε τα από το εικονίδιο ρυθμίσεων → *Show hidden files*.

## 3. Πρώτη ρύθμιση admin

1. Ανοίξτε `https://το-domain-σας/admin/`.
2. Θα εμφανιστεί η **Πρώτη ρύθμιση**: email και κωδικός τουλάχιστον 12 χαρακτήρων. **Δεν υπάρχουν προεπιλεγμένοι κωδικοί.** Η σελίδα κλείνει μόλις δημιουργηθεί ο πρώτος λογαριασμός.
3. Συνδεθείτε. Μετά από 5 λάθος προσπάθειες η σύνδεση κλειδώνει για 15 λεπτά.
4. **Ρυθμίσεις:** τηλέφωνο, email, διεύθυνση, συντεταγμένες χάρτη, ωράριο (τσεκάρετε «Το ωράριο είναι σωστό»), social, Google Business Profile.
5. **Πολυμέσα:** ανεβάστε το λογότυπο σε υψηλή ανάλυση και 3–4 φωτογραφίες τοπίου. Μετά, στις **Ρυθμίσεις → Εικόνες**, ορίστε το λογότυπο και τη φωτογραφία hero της αρχικής. Μέχρι τότε εμφανίζεται το ζωγραφισμένο τοπίο.

**Συντεταγμένες για τον χάρτη:** στο Google Maps κάντε δεξί κλικ στην πινέζα του γραφείου. Ο πρώτος αριθμός είναι το γεωγραφικό πλάτος, ο δεύτερος το μήκος.

## 4. SSL, https και non-www

1. hPanel → **Security → SSL**: ενεργοποιήστε το δωρεάν SSL και περιμένετε να δείξει *Active*.
2. Admin → **Ρυθμίσεις → SEO & analytics → Κανονικό URL**: γράψτε π.χ. `https://anv.gr` (χωρίς www, χωρίς / στο τέλος), τσεκάρετε την επιβεβαίωση και αποθηκεύστε. Από εκεί και πέρα κάθε `http://` και `www.` πάει με 301 στο κανονικό URL.
   Εναλλακτικά, ενεργοποιήστε τις 4 σχολιασμένες γραμμές στην αρχή του `.htaccess`.
3. **Μην ορίσετε κανονικό URL πριν λειτουργήσει το SSL**, γιατί το site θα ανακατευθύνει σε https που δεν απαντά.

## 5. Cache (LiteSpeed)

Οι σελίδες στέλνουν `Cache-Control: public, max-age=300`. Τα CSS/JS/fonts/εικόνες αποθηκεύονται για 1 χρόνο και ανανεώνονται αυτόματα όταν αλλάζουν (`?v=` στο URL).
Αν μετά από αλλαγή στο admin δεν βλέπετε το αποτέλεσμα: hPanel → **Performance → Cache Manager → Purge All**. Στο admin δεν γίνεται cache.

## 6. Search Console, sitemap και analytics

1. [Google Search Console](https://search.google.com/search-console) → Add property → **URL prefix** → `https://anv.gr/` → μέθοδος **HTML tag**. Αντιγράψτε μόνο την τιμή `content="…"` στο admin → Ρυθμίσεις → *Google Search Console*, αποθηκεύστε και πατήστε Verify.
2. Search Console → **Sitemaps** → υποβάλετε `sitemap.xml`.
3. GA4 (προαιρετικά): Measurement ID `G-XXXXXXX` στις Ρυθμίσεις. Το GA4 φορτώνει **μόνο αφού ο επισκέπτης πατήσει «Αποδοχή»** στο banner cookies. Το ίδιο ισχύει και για τον χάρτη Google.
4. Google Business Profile: βάλτε τον σύνδεσμο στις Ρυθμίσεις. Μπαίνει στο `sameAs` του schema.

Αυτόματα αρχεία: `/sitemap.xml` (με εικόνες), `/robots.txt` (επιτρέπει GPTBot, OAI-SearchBot, ClaudeBot, PerplexityBot, Google-Extended· ρυθμίζεται από το admin), `/llms.txt`, `/feed.xml`.

## 7. Περιεχόμενο

- **Σελίδες → Επεξεργασία:** κάθε σελίδα έχει εισαγωγή (άμεση απάντηση), TL;DR, βασικά σημεία, κείμενο σε markdown, FAQ, βήματα HowTo, πηγές, SEO πεδία και custom JSON-LD. Ο analyzer δίνει SEO και AEO score 0–100 όσο γράφετε και προειδοποιεί για keyword cannibalization.
- **Αλλαγή slug:** δημιουργεί αυτόματα 301 από την παλιά διεύθυνση (και για τις υποσελίδες) και συμπτύσσει τις αλυσίδες ανακατευθύνσεων.
- **Πρότυπο κείμενο:** όλες οι αρχικές σελίδες έχουν τσεκαρισμένο το «Περιέχει πρότυπο κείμενο». Όσο είστε συνδεδεμένοι στο admin, φαίνεται σχετική ένδειξη σε κάθε σελίδα, και ο πίνακας ελέγχου τις απαριθμεί. Όταν μπει το τελικό κείμενο, ξετσεκάρετε το πεδίο.
- **Εισαγωγή .md:** `# Τίτλος`, πρώτη παράγραφος = εισαγωγή, `## FAQ` με `### Ερώτηση` + απάντηση = FAQ, `## Πηγές`, `## Βασικά σημεία`, `## TL;DR`.
- **Πολυμέσα:** JPG/PNG/WebP/GIF έως 10 MB. Κάθε εικόνα ξανακωδικοποιείται, σμικρύνεται στα 2000 px, παίρνει όνομα αρχείου από το slug και αποκτά και έκδοση WebP.

## 8. 404 Monitor και ανακατευθύνσεις

- Το **404 Monitor** καταγράφει διευθύνσεις που δεν βρέθηκαν (hits, referrer, τελευταία επίσκεψη) και προτείνει προορισμό. Με ένα κλικ τις κάνετε 301, 302 ή 410, ή τις αγνοείτε. Οι αυτόματες σαρώσεις (`wp-login`, `.env`, `*.php` κ.λπ.) αγνοούνται.
- Οι **ανακατευθύνσεις** υποστηρίζουν 301/302/307/308/410/451, ακριβές ή regex ταίριασμα (με `$1`), ενεργοποίηση/απενεργοποίηση και μετρητή hits. Απορρίπτουν πηγή = προορισμό και βρόχους. Έχουν και εργαλείο «Δοκιμή URL».

## 9. Backup και ενημέρωση

- Admin → **Πίνακας ελέγχου → Λήψη backup (.zip)**: βάση δεδομένων και εικόνες. Κάντε το τουλάχιστον μία φορά τον μήνα και πριν από κάθε ενημέρωση.
- Επαναφορά: αντικαταστήστε `data/site.sqlite` και `uploads/` με αυτά του backup.
- Ενημέρωση κώδικα: ανεβάστε τα νέα αρχεία **χωρίς** να αντικαταστήσετε τους φακέλους `data/` και `uploads/`.
- Το Hostinger κρατά επίσης αυτόματα backups (hPanel → Files → Backups).

## 10. Ασφάλεια (τι κάνει ήδη το site)

Prepared statements (PDO), escaping σε όλη την έξοδο, CSRF σε κάθε φόρμα του admin, `password_hash`, κλείδωμα μετά από 5 αποτυχίες για 15 λεπτά, session cookies με HttpOnly/SameSite/Secure, `noindex` στο admin, allow-list sanitizer (χωρίς `<script>`, `on*`, `javascript:` ή επικίνδυνα `data:`, iframe μόνο από YouTube/Vimeo/Google Maps), έλεγχος εικόνων με `getimagesize()` και MIME. Χωρίς εκτέλεση PHP στο `uploads/`, και με τους φακέλους `app/`, `data/`, `views/` προστατευμένους.

Αν χρειαστεί διάγνωση σφάλματος: δημιουργήστε κενό αρχείο `data/.debug` (εμφανίζει τα σφάλματα) και **σβήστε το αμέσως μετά**. Τα σφάλματα καταγράφονται πάντα στο `data/php-error.log`.

## 11. Τοπική δοκιμή

```bash
php -S localhost:8000 index.php
```

Δοκιμές (σε καθαρή εγκατάσταση, με τον server να τρέχει):

```bash
python3 tests/e2e.py http://localhost:8000
```

Η τελευταία δοκιμή κλειδώνει σκόπιμα τη σύνδεση για 15 λεπτά.

Για νέα καθαρή εγκατάσταση: σβήστε το `data/site.sqlite` (και τα `-wal`/`-shm`) και ό,τι υπάρχει στο `uploads/` εκτός από τα `.htaccess` και `index.html`.
