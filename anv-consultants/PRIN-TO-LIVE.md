# ΠΡΙΝ ΤΟ LIVE: ANV

Ό,τι είναι προσωρινό ή λείπει. Ο πίνακας ελέγχου του admin δείχνει τα περισσότερα αυτόματα («Πριν το live»).

## Αποφάσεις / στοιχεία από το γραφείο
- [ ] **Επωνυμία:** «ANV Consultants» ή «ANV Financial Advisors»; Τώρα είναι «ANV Financial Advisors» (όπως στο λογότυπο). Αλλάζει από Ρυθμίσεις → Επωνυμία.
- [ ] **Νομική επωνυμία και ΑΦΜ**, για το footer, το schema και την Πολιτική απορρήτου.
- [ ] **Λογότυπο σε υψηλή ανάλυση** (SVG/PDF ή PNG 1200px+). Το τρέχον είναι 317×116 px.
- [ ] **Τηλέφωνο, email, διεύθυνση, ΤΚ** (Ρυθμίσεις).
- [ ] **Συντεταγμένες χάρτη** (πλάτος/μήκος) για ακριβή πινέζα.
- [ ] **Ωράριο:** το τρέχον Δευ–Παρ 09:00–17:00 είναι ενδεικτικό. Διορθώστε το και τσεκάρετε «Το ωράριο είναι σωστό».
- [ ] **Social profiles** και **Google Business Profile**.
- [ ] Με ποιες **ασφαλιστικές εταιρείες** συνεργάζεστε, και αν επιτρέπεται να αναφερθούν.
- [ ] Στοιχεία **άδειας/μητρώου** διαμεσολαβητή ασφάλισης, αν απαιτείται να εμφανίζονται.

## Κείμενα (ο Αχιλλέας)
Όλες οι 26 σελίδες έχουν **πρότυπο κείμενο**. Βλ. Admin → Πίνακας → «Σελίδες με πρότυπο κείμενο».
- [ ] Αρχική: τίτλος, εισαγωγή, κείμενο, βήματα.
- [ ] Λογιστικά + 7 υποσελίδες.
- [ ] Ασφάλειες + 5 υποσελίδες.
- [ ] Ρεύμα + 4 υποσελίδες (επιβεβαίωση των 3 βημάτων αλλαγής παρόχου).
- [ ] Η εταιρεία.
- [ ] FAQ: έλεγχος όλων των απαντήσεων (π.χ. «Χρειάζεται ραντεβού;»).
- [ ] **Πολιτική απορρήτου, Cookies, Όροι:** έλεγχος από νομικό σύμβουλο.
- [ ] Συμπλήρωση πεδίου «Συντάκτης» στις σελίδες υπηρεσιών (βελτιώνει το AEO).
- [ ] Ξετσεκάρισμα του «Περιέχει πρότυπο κείμενο» σε κάθε σελίδα που ολοκληρώνεται.

## Εικόνες
- [ ] 3–4 φωτογραφίες τοπίου (Unsplash/Pexels, ελεύθερη άδεια) → Πολυμέσα → Ρυθμίσεις → «Φωτογραφία hero αρχικής» και «Εικόνα hero» ανά σελίδα. Μέχρι τότε εμφανίζεται το ζωγραφισμένο τοπίο.
- [ ] Εικόνα κοινοποίησης 1200×630 με το τελικό λογότυπο (υπάρχει προσωρινή).

## Τεχνικά (κατά το deploy)
- [ ] Backup του τρέχοντος `public_html` πριν από το upload.
- [ ] PHP 8.2+ και επεκτάσεις (README §1).
- [ ] Δημιουργία admin στο `/admin/` **αμέσως** μετά το upload.
- [ ] SSL ενεργό → Ρυθμίσεις → Κανονικό URL `https://…` (χωρίς www).
- [ ] Search Console: επαλήθευση + υποβολή `sitemap.xml`.
- [ ] GA4 Measurement ID (προαιρετικά).
- [ ] Έλεγχος σε κινητό: κλήση από το κουμπί, άνοιγμα email, χάρτης μετά την αποδοχή cookies.
- [ ] Πρώτο backup από το admin.
- [ ] Μετά από 1–2 εβδομάδες: έλεγχος του 404 Monitor.
